三步就能用

不需要装 Python，不需要命令行，解压即用。

1

打开 QQ音乐并登录

保持客户端在后台运行即可，不用播放歌曲。解密需要它提供解密钥。

2

选好歌所在的文件夹

解压后双击 TuneFree.exe，选择存放 .mflac 文件的目录。

3

转换完成的 MP3 在输出目录里，文件名和原曲一致，可以直接拷进手机。

它做了什么

解密部分靠进程内取密钥，转码部分交给 ffmpeg。

🔓

解密 .mflac / .mgg

通过注入 QQ音乐进程调用它自己的解密函数，不依赖云端，也不需要会员。

递归处理子文件夹，按原文件名输出到 output/mp3、output/flac。

  • 杀毒软件会报警——程序用 Frida 往 QQ音乐进程里注入代码，这个行为本身就很像病毒。加信任区即可，源码是公开的。

使用帮助

界面上就三个区域：上面选参数，中间是命令预览，下面是日志。

🖥️ 界面上都有什么

  • 输入目录：放 .mflac 的文件夹，留空就用程序所在目录。
  • 输出目录：根目录模式会自动在里面建 mp3 / flac 子文件夹；勾选「使用独立输出目录」可以分别指定。
  • MP3 比特率：默认 192k，追求音质选 320k，文件会大一些。
  • 输出格式：仅 MP3 / 仅 FLAC / 两者都留。
  • 日志：每一步都写在这，出错时先看它。

🚀 操作顺序

  1. 打开 QQ音乐并登录，保持运行（不用播放）。
  2. 双击 TuneFree.exe。
  3. 「浏览」选择歌曲所在文件夹。
  4. 选输出格式和比特率（默认就行）。
  5. 点「开始执行」，等进度跑完。
  6. 去输出目录取文件。

⌨️ 命令行用法（可选）

需要批量或写脚本时，可以绕过界面直接调用 main.exe。

参数说明
-i / --input输入目录，默认当前目录
-o / --output输出根目录，默认 ./output
--mp3-dir / --flac-dir分别指定 MP3 / FLAC 输出位置
-b / --bitrateMP3 比特率，默认 192k
--keep-flac保留解密出的 FLAC
--no-mp3只输出 FLAC，不转 MP3
--force已存在的 MP3 也重新生成
 
main.exe -i "D:\下载" -o "D:\我的音乐" -b 320k --keep-flac

常见问题

点开看答案，包括那些看起来像 bug 其实不是的情况。

提示「请确保 QQ音乐客户端正在运行后重试」

先把 QQ音乐打开并登录，再启动 TuneFree。如果开着还是报这个，试试以管理员身份运行（有些环境下注入需要更高权限）。

解密报 invalid size 或「QQ音乐版本不匹配」

说明 QQ音乐更新后换了解密函数的符号名，内置的脚本找不到它了。新版 TuneFree 会直接告诉你缺哪个符号，而不是丢一个 invalid size 出来。

  • 先把 QQ音乐升级到最新，再看 TuneFree 有没有新版；
  • 临时办法：把 QQ音乐降级到上一个版本；
  • 都不行就来 QQ 群反馈，附上程序里那句版本不匹配的提示。
解密成功，但转 MP3 全部失败

日志里如果出现 Permission denied 或返回码 -13，是 ffmpeg 没有写文件的权限，不是歌曲本身有问题。常见原因：

  • 杀毒软件（360、火绒、Defender）拦截了 ffmpeg 写盘——加信任区；
  • 程序放在受管控的目录里——挪到 D 盘或桌面这种普通位置再解压；
  • 输出目录是只读的或者别的程序正占着文件。

新版遇到这种情况会自动换一种方式写文件（让 ffmpeg 输出到内存，再由程序落盘），多数环境能直接绕过。

有几首歌死活转不出来

少数文件需要先在 QQ音乐里播放一遍，让它把完整数据落到本地缓存，再回来转换。也可以把那几首单独重下一次。

杀毒软件报毒怎么办

这是 Frida 注入导致的误报，源码全部公开在 GitHub 上，可以自己核对。把程序目录加进信任区，或者临时关掉实时防护完成转换再打开。

子文件夹里的歌会处理吗？

会，递归扫描输入目录下所有层级的 .mflac / .mgg。

怎么保留无损 FLAC？

输出格式选「两者均保留」，或者命令行加 --keep-flac。只要 FLAC 不要 MP3 就选「仅 FLAC」。

转换到一半关掉了，要重头再来吗？

不用。重新运行会自动跳过已经生成的文件，只补没转完的。想强制重转就勾上「重新生成已存在的 MP3」。

支持 Mac / Linux 吗？

目前只发布 Windows 64 位版本。核心逻辑是 Python，理论上可以自己跑起来，但没有打包，也没有测试过。
