它做了什么

解密部分靠进程内取密钥，转码部分交给 ffmpeg。

🔓

解密 .mflac / .mgg

通过注入 QQ音乐进程调用它自己的解密函数，不依赖云端，也不需要会员。

🎚️

三种输出选择

只要 MP3、只要无损 FLAC，或者两个都留。比特率支持 128k / 192k / 320k。

实时进度

⚠️ 下载前先看一眼，能省掉大部分问题：
  • 杀毒软件会报警——程序用 Frida 往 QQ音乐进程里注入代码，这个行为本身就很像病毒。加信任区即可，源码是公开的。
  • 第一次双击被蓝色窗口挡住——那是 SmartScreen，不是报毒。先右键压缩包 → 属性 → 勾选「解除锁定」→ 再解压就不会再弹；已经解压的，点「更多信息」→「仍要运行」。
  • 必须先打开 QQ音乐，没开的话程序会直接提示并退出。
  • 音质只支持「标准 / HQ / SQ」三档——开了 Hi-Res（臻品音质）、臻品母带、杜比全景声的歌，拿到的不是普通音频流，转换一定失败。
  • 换个盘解压——放在某些受管控的目录（比如系统盘的用户目录、企业管控盘）里，ffmpeg 可能没有写文件权限。

使用帮助

界面上就三块：上面选参数，中间是运行日志，最下面是开始按钮。

🖥️ 界面上都有什么

  • 输入目录：放 .mflac、.mgg 的文件夹，留空则为程序所在目录。
  • 输出目录：转换结果都放这里，程序会自动在里面建 mp3 / flac 子文件夹。
  • MP3 比特率：默认 192k，追求音质选 320k，文件会大一些。
  • 输出格式：仅 MP3 / 仅 FLAC / 两者都留。
  • 日志：每一步都写在这，出错时可以把这个发给AI工具看看，或者联系作者。

🚀 操作顺序

  1. 打开 QQ音乐并登录，保持运行即可。
  2. 双击 TuneFree.exe。
  3. 选中输入目录后方的「浏览」选择歌曲文件所在文件夹。
  4. 选输出格式和比特率。
  5. 点「开始执行」，等进度跑完。
  6. 去输出目录取文件。

常见问题

点开看答案，包括那些看起来像 bug 其实不是的情况。

提示「请确保 QQ音乐客户端正在运行后重试」

先把 QQ音乐打开并登录，再启动 TuneFree。如果开着还是报这个，试试以管理员身份运行（有些环境下注入需要更高权限）。

解密报 invalid size 或「QQ音乐版本不匹配」

说明 QQ音乐更新后换了解密函数的符号名，内置的脚本找不到它了。

  • 先把 QQ音乐升级到最新，再看 TuneFree 有没有新版；
  • 临时办法：把 QQ音乐 降级到上一个版本；
  • 都不行就来 QQ 群反馈，附上程序里的报错日志。
解密成功，但转 MP3 全部失败

日志里如果出现 Permission denied 或返回码 -13，是 ffmpeg 没有写文件的权限，不是歌曲本身有问题。常见原因：

  • 杀毒软件（360、火绒、Defender）拦截了 ffmpeg 写盘——加信任区；
  • 也可能是程序放在受管控的目录里————尝试挪到 D 盘或桌面这种普通位置再试试；
  • 输出目录是只读的或者别的程序正占着文件。
有几首歌死活转不出来

先看音质。程序只支持 标准 / HQ / SQ 三档；如果这首歌在 QQ音乐里下的是 Hi-Res（臻品音质）、臻品母带、杜比全景声，拿到的不是普通音频流，转换必然失败——把那首歌的音质改回 SQ 或更低，重新下载一次就行。

确认已经是标准/HQ/SQ 还转不出来，少数文件需要先在 QQ音乐里播放一遍，让它把完整数据落到本地缓存，再回来转换。也可以把那几首单独重下一次。

双击提示「Windows 已保护你的电脑」，蓝色窗口不让运行

那是 SmartScreen 的「未知发布者」提示，不是报毒。两个办法任选：

蓝窗口里点「更多信息」，再点右下角「仍要运行」。同一份文件只需要点这一次。

想彻底不弹只能买代码签名证书（正规证书一年上千元），项目是免费的，暂时没走这条路。

杀毒软件报毒怎么办

这是 Frida 注入导致的误报，源码全部公开在 GitHub 上，不放心可以自己核对。把程序目录加进信任区，或者临时关掉实时防护完成转换再打开。

子文件夹里的歌会处理吗？

会，递归扫描输入目录下所有层级的 .mflac / .mgg。

怎么保留无损 FLAC？

输出格式选「两者均保留」，或者命令行加 --keep-flac。只要 FLAC 不要 MP3 就选「仅 FLAC」。

转换到一半关掉了，要重头再来吗？

不用。重新运行会自动跳过已经生成的文件，只补没转完的。想强制重转就勾上「重新生成已存在的 MP3」。

支持 Mac / Linux 吗？

目前只发布 Windows 64 位版本。核心逻辑是 Python，理论上可以自己跑起来，但没有打包，也没有测试过。
