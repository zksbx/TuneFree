把 QQ音乐下的歌
变成任何播放器都能放的 MP3

TuneFree 把 .mflac / .mgg 这类加密音频，一键解密成无损 FLAC，再转成通用 MP3。 全程在你的电脑上完成，不上传、不联网。

备用通道是蓝奏云：不用登录、不用注册。提取码 0211，点按钮会自动复制。

三步就能用

不需要装 Python，不需要命令行，解压即用。

1

打开 QQ音乐并登录

保持客户端在后台运行即可，不用播放歌曲。

2

选好歌所在的文件夹

解压后双击 TuneFree.exe，点顶栏左侧的文件夹按钮选存放 .mflac / .mgg 的目录；也可以直接把文件夹拖进窗口。

3

点「开始转换」

进度会浮在窗口右下角，跑完弹完成提示；去 output\mp3 拿 MP3，文件名和原曲一致。

它做了什么

解密部分靠进程内取密钥，转码部分交给 ffmpeg。

🔓

解密 .mflac / .mgg

通过注入 QQ音乐进程调用它自己的解密函数，不依赖云端，也不需要会员。

🎚️

默认直接出 320k

解密完顺手转 MP3，比特率可选 320k / 256k / 192k / 128k；想留无损就在转换选项里勾一下。

🏷️

每首歌走到哪一步

格式胶囊写着 MFLAC/MGG 是还没解密，FLAC/OGG 是解密好了，MP3 是转完了。

🗂️

胶囊一键筛选

全部 / 未解密 / 各格式一键切换，计数实时更新；点「筛选」还能按歌手过滤，只留想听的那几位。

🎧

试听与沉浸播放页

双击列表里的歌直接播放，播放条带封面和两行歌词；点封面或「沉浸」进整页播放页，右边是中英双语歌词。

🔀

想听哪版听哪版

同一首歌有 MP3、FLAC、OGG 几份文件时，播放条上直接切；在哪个格式分类里双击，就优先播那一版。

🪟

迷你播放器

缩成一个小窗浮在桌面一角，封面、歌名、当前那句歌词和进度都在，拖到哪下次就回到哪。

📥

拖进来就开始

把文件夹拖到窗口上就能扫描；媒体键、Ctrl+O、Ctrl+F、Ctrl+R 这些快捷键也都配好了。

🔔

托盘常驻与完成通知

关窗口不退出，转换在后台继续跑；转完发一条系统通知，点托盘图标就回来。

🎨

配色和字号自己调

浅色 / 深色内置，还能存三套自定义配色；主界面和歌词字号分开调。

⚡

多线程 + 断点续跑

按 CPU 核数自动开转码线程、大文件先排；中途中断的话，重跑跳过已完成的。

🛡️

不联网

除了检查更新，程序不会主动连接任何服务器。歌单和文件都留在本地。

⚠️ 下载前先看一眼，能省掉大部分问题：
  • 杀毒软件会报警——程序用 Frida 往 QQ音乐进程里注入代码，这个行为本身就很像病毒。加信任区即可，源码是公开的。
  • 第一次双击被蓝色窗口挡住——那是 SmartScreen，不是报毒。先右键压缩包 → 属性 → 勾选「解除锁定」→ 再解压就不会再弹；已经解压的，点「更多信息」→「仍要运行」。
  • 必须先打开 QQ音乐并登录——程序每两秒探一次，QQ音乐打开后顶栏的连接状态会自动变绿，不用重启程序。
  • 音质只支持「标准 / HQ / SQ」三档——开了 Hi-Res（臻品音质）、臻品母带、杜比全景声的歌，拿到的不是普通音频流，转换一定失败。
  • 换个盘解压——放在某些受管控的目录（比如系统盘的用户目录、企业管控盘）里，ffmpeg 可能没有写文件权限。

使用帮助

界面上就三块：顶栏选文件夹、中间曲库列表、底部播放条。

🖥️ 界面上都有什么

  • 歌曲文件夹：放 .mflac、.mgg 的文件夹，点顶栏左侧的文件夹按钮就能换，也可以直接把文件夹拖进窗口。
  • 筛选胶囊：全部 / 未解密 / MFLAC / MGG / FLAC / OGG / MP3 一键切换，计数实时更新；点最右的「筛选」按歌手过滤。
  • 列表：歌名、歌手、格式胶囊、大小、时长；工具行右侧可切排序，双击试听，右键或用行尾「⋯」删行。
  • 转换选项：MP3 品质、是否保留解密出的无损文件、是否重转已存在的。
  • 设置：左侧导航分五页——外观（配色、自定义颜色、字号）、识别格式、行为（托盘、通知、媒体键、迷你窗）、缓存、关于。

🚀 操作顺序

  1. 打开 QQ音乐并登录，保持运行即可。
  2. 双击 TuneFree.exe。
  3. 点顶栏左侧的文件夹按钮选歌所在的目录，或者把文件夹拖进窗口。
  4. 需要的话点「转换选项」调比特率、是否保留无损。
  5. 点「开始转换」，窗口右下角会显示进度；开了托盘常驻的话，转完还会发系统通知。
  6. 去 output\mp3 取文件。

常见问题

点开看答案，包括那些看起来像 bug 其实不是的情况。

提示「请确保 QQ音乐客户端正在运行后重试」

先把 QQ音乐打开并登录，再启动 TuneFree。如果开着还是报这个，试试以管理员身份运行（有些环境下注入需要更高权限）。

解密报 invalid size 或「QQ音乐版本不匹配」

说明 QQ音乐更新后换了解密函数的符号名，内置的脚本找不到它了。

  • 先把 QQ音乐升级到最新，再看 TuneFree 有没有新版；
  • 临时办法：把 QQ音乐 降级到上一个版本；
  • 都不行就来 QQ 群反馈，附上程序里的报错日志。
解密成功，但转 MP3 全部失败

日志里如果出现 Permission denied 或返回码 -13，是 ffmpeg 没有写文件的权限，不是歌曲本身有问题。常见原因：

  • 杀毒软件（360、火绒、Defender）拦截了 ffmpeg 写盘——加信任区；
  • 也可能是程序放在受管控的目录里————尝试挪到 D 盘或桌面这种普通位置再试试；
  • output 目录是只读的，或者别的程序正占着文件。
有几首歌死活转不出来

先看音质。程序只支持 标准 / HQ / SQ 三档；如果这首歌在 QQ音乐里下的是 Hi-Res（臻品音质）、臻品母带、杜比全景声，拿到的不是普通音频流，转换必然失败——把那首歌的音质改回 SQ 或更低，重新下载一次就行。

确认已经是标准/HQ/SQ 还转不出来，少数文件需要先在 QQ音乐里播放一遍，让它把完整数据落到本地缓存，再回来转换。也可以把那几首单独重下一次。

双击提示「Windows 已保护你的电脑」，蓝色窗口不让运行

那是 SmartScreen 的「未知发布者」提示，不是报毒。两个办法任选：

蓝窗口里点「更多信息」，再点右下角「仍要运行」。同一份文件只需要点这一次。

想彻底不弹只能买代码签名证书（正规证书一年上千元），项目是免费的，暂时没走这条路。

杀毒软件报毒怎么办

这是 Frida 注入导致的误报，源码全部公开在 GitHub 上，不放心可以自己核对。把程序目录加进信任区，或者临时关掉实时防护完成转换再打开。

子文件夹里的歌会处理吗？

会，递归扫描所选文件夹下所有层级的 .mflac / .mgg。

怎么保留无损 FLAC？

输出格式选「两者均保留」，或者命令行加 --keep-flac。只要 FLAC 不要 MP3 就选「仅 FLAC」。

转换到一半关掉了，要重头再来吗？

不用。重新运行会自动跳过已经生成的文件，只补没转完的。想强制重转就把「重新生成已存在的 MP3」右边的开关打开。

支持 Mac / Linux 吗？

这里发布的 Windows 版是唯一官方版本——注入目标 QQ音乐只有 Windows 版。

macOS 版由 Dora-z 独立开发维护，不是本项目的移植：它不注入进程，改为在本机复现解密算法；新版 musicex 格式则读取本机 QQ音乐的登录态，向官方接口取这首歌的密钥。源码、安装包和问题反馈都在他的仓库里。

Linux 目前没有人维护。
