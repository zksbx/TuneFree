🎵 TuneFree

把 QQ音乐下载的加密歌曲（.mflac / .mgg）还原成任何播放器都能放的 FLAC / OGG · v3.1.2

TuneFree 在 QQ音乐进程里调用它自己的解密函数，把加密文件还原成正常的 FLAC / OGG，不转码。解密完成后如果文件里没有封面，会自动从 QQ音乐的专辑图缓存补一张。全程在你自己的电脑上完成，不上传任何文件。

.mflac  ──解密──▶  .flac
.mgg    ──解密──▶  .ogg

✨ 功能特点

  • 批量解密 自动递归子文件夹，一次处理整库。
  • 补封面 解密后文件里没有图，就从 QQ音乐的专辑图缓存挑最大的一张写进去。
  • 看得清 列表里每首歌都标着它现在的格式：没解密是 MFLAC / MGG，解密后是 FLAC / OGG。
  • 筛选 顶部一排格式胶囊（全部 / 未解密 / MFLAC / MGG / FLAC / OGG），点一下就是筛选，计数实时更新；最右的「筛选」还能按歌手过滤。
  • 能听 双击列表里的歌就地试听，底部播放条带封面和两行歌词；点封面或「沉浸」进整页播放页，右边是中英双语歌词。
  • 选择模式 点「选择」后可以按文件勾选，批量删除源文件或输出文件。
  • 好看 浅色 / 深色两套内置配色，另可自存三套自定义配色；主界面字号、歌词字号都能调。
  • 自动更新 启动时检查新版本，同意后原地覆盖升级，配色、字号、解密选项全部保留。
  • 后台 关窗口时收进托盘、解密继续在后台跑、解完发系统通知，都在设置 → 行为里开；迷你播放器和全局媒体键也在那一页。

📋 系统要求

  • 操作系统：Windows 10 / 11（64 位）
  • 运行环境：必须提前打开 QQ音乐电脑客户端并登录，保持运行（不需要播放歌曲）。解密依赖它进程里的密钥。
  • 音质限制：只支持「标准 / HQ / SQ」。Hi-Res（臻品音质）、臻品母带、杜比全景声拿到的不是普通音频流，解密会失败。

⚠️ 先开 QQ音乐，再开 TuneFree。顺序反了会看到「未连接」，点一下连接胶囊可以重连。

🚀 三步就能用

  1. 打开 QQ音乐并登录，放在后台就行。
  2. 双击 TuneFree.exe，点顶栏左侧的文件夹按钮选存放 .mflac / .mgg 的目录（也可以直接把文件夹拖进窗口）。
  3. 点「开始解密」，右下角会浮出进度条；跑完去 output\flac / output\ogg 拿文件。

⚙️ 解密选项

点顶栏的「解密选项」，这些设置对下一次点「开始解密」生效：

  • 没有封面时自动补上：从 QQ音乐的专辑图缓存里按「歌手 + 专辑」挑最大的一张写进文件。
  • 重新解密已存在的文件：默认跳过已经解出来的，勾上就全部重来一遍。

📁 输出结构

你选中的歌曲文件夹
└─ output
   ├─ flac   .mflac 解密出的 FLAC
   └─ ogg    .mgg 解密出的 OGG

🔤 文件名格式

程序按「歌名 - 歌手」拆名字。如果你下载的文件是「歌手 - 歌名」或者只有歌名，去设置里把「文件名格式」改成对应那一档，列表里的歌名和歌手会立刻重算。

文件名结尾的 _H、_SQ、_DOLBY 这类音质后缀会自动去掉；像 G_E_M邓紫棋 这种带下划线的歌手名不会被误伤。

⚠️ 注意事项

🔒 杀毒软件误报

程序用 Frida 往 QQ音乐进程里注入代码，这个行为和恶意软件一模一样，所以杀软基本都会报。把 TuneFree 目录加进信任区即可；源码全部公开，可以自己看每一行在做什么。

🛡️ 首次运行被蓝色窗口拦住

那是 SmartScreen 的「未知发布者」提示，不是报毒——没买代码签名证书的 exe 第一次运行都会这样。

还没解压：右键 zip → 属性 → 勾选最下面的「解除锁定」→ 确定，再解压，以后都不弹。

已经解压了：蓝窗口里点「更多信息」→「仍要运行」，同一份文件点一次就够。

🎵 QQ音乐必须运行

没有 QQMusic.exe 就没有密钥，程序会显示「未连接」。打开它、登录、再回 TuneFree 点连接胶囊。

💾 磁盘空间

解密出来的文件和原文件差不多大（FLAC）或小一些（OGG），没有转码这一步，所以不会额外膨胀。

❓ 常见问题

  • Q：顶栏一直显示「未连接」。
    A：先确认 QQ音乐开着并已登录，再点那个胶囊重连。QQ音乐刚更新过也可能要等 TuneFree 适配。
  • Q：双击一首歌提示「这个使不得 请先解密再试」。
    A：那首歌还没解密，先点「开始解密」。提示是浮窗，几秒后自己消失。
  • Q：解密报 invalid size 或提示版本不匹配。
    A：QQ音乐更新后改了内部函数名。把 QQ音乐降级到可用版本，或等 TuneFree 适配新版。
  • Q：解密出来没有封面。
    A：「同时下载专辑图片」只是让 QQ音乐把图存进它自己的缓存。TuneFree 解密后会去缓存里按「歌手 + 专辑」找图写进文件；缓存没有就保持原样，可以在解密选项里关掉自动补封面。
  • Q：有少数歌死活解不出来。
    A：先看音质是不是 Hi-Res / 臻品母带 / 杜比全景声——这几档不支持。是标准 / HQ / SQ 的话，先在 QQ音乐里播放一遍再试。
  • Q：胶囊上 MGG 是 0，但文件夹里明明有。
    A：MGG / MFLAC 这两个胶囊统计的是磁盘上的文件（不管解没解密）；如果一个都没有，说明它们已经被整理到别处了。
  • Q：界面字太小 / 太大。
    A：设置 → 外观 → 字号，主界面和歌词可以分开调。

🛠️ 命令行

不开界面也能跑，适合写进脚本批量处理：

参数说明示例
-i / --input输入目录，默认当前目录TuneFree.exe --cli -i "D:\下载"
-o / --output输出根目录，默认 ./outputTuneFree.exe --cli -o "E:\音乐"
--flac-dir / --ogg-dir分别指定 FLAC / OGG 输出位置--flac-dir "D:\无损"
--no-cover不自动补封面--no-cover
--force已经解出来的文件也重新解密--force
