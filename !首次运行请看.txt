TuneFree 首次运行说明
========================================

你可能遇到的情况
----------------------------------------
双击 TuneFree.exe 时，会先跳出一个蓝色的窗口：
「Windows 已保护你的电脑」，下面写着「未知发布者」。

这不是杀毒软件报毒，是 Windows 自带的 SmartScreen 在提醒：
这个程序没有花钱买代码签名证书（一年几百到几千块），
系统暂时不认识它。免费软件基本都是这个待遇。


怎么打开
----------------------------------------
1. 点这个蓝色窗口里的「更多信息」
2. 点右下角出现的「仍要运行」

只需要点这一次，同一份文件以后直接双击就能开。


如果这一步被挡住了
----------------------------------------
个别电脑装了企业管控或第三方安全软件，会把「仍要运行」藏起来。
那就先把 TuneFree.exe 加进信任区，再双击：

Windows Defender：
  设置 → 隐私和安全性 → Windows 安全中心 → 病毒和威胁防护
  → 管理设置 → 排除项 → 添加排除项 → 选择 TuneFree.exe

360 / 火绒 / 腾讯电脑管家：在「信任区 / 白名单」里添加整个
TuneFree 文件夹即可。


为什么会被拦
----------------------------------------
· 程序要用 Frida 往 QQ音乐进程里注入代码，去读解密后的音频数据。
  这个行为本身跟恶意软件很像，所以系统会格外警惕。
· 程序没有数字签名证书，第一次运行必然要你手动放行。
· 源码完全公开，每一行在做什么都能自己看：
  https://github.com/zksbx/TuneFree
